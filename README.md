# Sistema de Controle de Estoque em Python

## Sobre o projeto

Este projeto foi desenvolvido em Python para simular o controle de um estoque de pallets.

A aplicação permite registrar produtos, consultar informações, controlar endereços de armazenamento e realizar transferências de pallets entre diferentes posições do estoque.

O projeto foi criado com foco em praticar programação, lógica computacional e aplicação de conceitos de tecnologia em um cenário real de logística.

## Funcionalidades

- Cadastro de pallets
- Consulta de pallets
- Transferência de pallets
- Controle de Endereços
- Identificação de localização no chão
- Identificação de posição em porta-palete
- Verificação de localização ocupada
- Validação da quantidade de caixas
- Atualização da localização do pallet
- Armazenamento das informações em JSON
